# Soggfy v3.0.0-rc.12

RC12 cleans up the release packaging. There is now one Windows x64 release ZIP with everything included.

## One release file

- `Soggfy-v3.0.0-rc.12-Windows-x64.zip` is the only uploaded build asset.
- Normal automatic mode is at the ZIP root with `version.dll`, configuration, scripts and documentation.
- Optional launcher mode is inside the `Launcher` folder with `Soggfy.exe`, `Soggfy.dll` and its configuration file.
- Build information, checksums, licenses, changelog, release notes and helper scripts are all inside the same ZIP.
- The separate raw DLL, checksum file, build-info asset and second launcher ZIP are no longer published separately.

GitHub still adds its own automatic `Source code (zip)` and `Source code (tar.gz)` links to every release; those are generated by GitHub and are not separate Soggfy build packages.

RC12 contains the same runtime changes as RC11, including the Floggfy v1.1.0 sync, RC10 accelerated-playback validation and RC9 Ogg replay handling.
